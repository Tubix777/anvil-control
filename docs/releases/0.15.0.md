# Anvil Control 0.15.0-alpha — motion update

Five-page directional slide/fade navigation, staggered one-pass card glints,
theme-colored hover borders, mouse/keyboard click rings and theme-change fades.
The decorative GPU fan now uses five curved blades and an activity rim.

Animations release their work when the window hides or motion is disabled.
Rapid navigation restores the outgoing page's position before the next transition.
The existing animation switch, seven palettes, keyboard semantics and monitoring-only
guards are preserved. No fan curve, profile, RGB permission or privileged helper changes.

Validation: 102 automated tests passed locally with Qt 6.11.2 in offscreen mode,
including animation input/lifecycle checks and mocked hardware-action assertions.
Package launch checks and artifact evidence are recorded after the build.
Synthetic previews do not claim physical fan behavior or supported hardware.
